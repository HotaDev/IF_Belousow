# Описание проекта:

Тестирование API сайтов https://reqres.in и https://rickandmortyapi.com/api

## Основой функционал проекта:

В проекте реализованы два теста:

1. Поиск и сравнение персонажей в сериале "Рик и Морти"

   Этапы теста:

    * Найти информацию по персонажу Морти Смит. Выбрать из ответа последний эпизод, где
      появлялся Морти.
    * Получить из списка последнего эпизода последнего персонажа.
    * Получить данные по местонахождению и расе этого персонажа.
    * Проверить, этот персонаж той же расы и находится там же где и Морти?


2. Создание пользователя и проверка кода ответа на сайте [reqres.in](https://reqres.in)

   Этапы теста:

    * Создать тест запрос для создания пользователя;
    * Проверить, что получили ответ 201;
    * Свериться, что полученный response имеет валидные данные

## Дополнительный функционал:

- Возможность менять входные данные в файле config.properties;
- Тесты переведены на Cucumber
- Отображение результатов выполненных тестов в Allure
- Отображение HTTP-запросов и ответов в Allure

## Запуск тестов и просмотр отчета

- для запуска теста выполнить в терминале команду ``mvn clean test``
- (При необходимости) для генерации отчета выполнить в терминале команду ``mvn allure:report``
- для просмотра отчета выполнить в терминале команду ``mvn allure:serve``
