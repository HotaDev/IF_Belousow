Описание проекта:

Тестирование работы сайта "https://edujira.ifellow.ru/"

Основой функционал проекта:

1. Тестирование входа в Jira. Можно изменять входные данные в файле config.properties(данные login, pass);
2. Тестирование возможности перехода в проект "Test";
3. Проверка общего количества задач
4. Тестирование возможности поиска задачи. Можно изменять входные данные в файле config.properties(данные find.task);
5. Тестирование возможности создания бага, а также перевода его в закрытый статус.

Дополнительный функционал:

- Возможность менять входные данные в файле config.properties;
- Отображение логов при выполнении каждого теста
- Отображение результатов выполненных тестов в Allure

Этапы проверки и/или тестирования проекта

1. Загрузить проект
2. Установить локально maven
3. Запустить в терминале команду mvn clean test
4. Запустить в терминале команду mvn allure:serve
